# Factor-Based Asset Selection & Robust Portfolio Optimisation

## Objective
Develop a quantitative investment framework for selecting assets using systematic factors and constructing a diversified portfolio through risk-return optimisation.

## Methodology
- Factor-based asset ranking and selection
- Momentum, volatility and Sharpe-based factor analysis
- Correlation and covariance analysis
- Portfolio construction and weight optimisation
- Equal-weight benchmark comparison
- Walk-forward validation
- Out-of-sample testing
- Regime robustness analysis
- Parameter sensitivity analysis
- Transaction-cost sensitivity

## Portfolio
Selected assets:
- AAPL
- GOOG
- META

Optimised portfolio weights:
- AAPL: 40%
- GOOG: 40%
- META: 20%

Equal-weight allocation was retained as the benchmark for evaluating the optimised portfolio.

## Validation
The framework was evaluated using chronological out-of-sample testing and walk-forward validation to reduce look-ahead bias and assess parameter stability.

## Tools

- pandas
- NumPy
- SciPy

- yfinance

## Key Outcome
The project demonstrates a complete quantitative investment workflow from factor-based asset selection through portfolio construction, optimisation and robustness testing.
